# Cyber Futuristic Portfolio 2026 🚀

Website portofolio interaktif ultra premium berkonsep Cyber Futuristic yang dibangun tanpa framework JavaScript eksternal (Pure Vanilla JS) & disempurnakan dengan Tailwind CSS.

## 🌟 Fitur Utama
* **Visual Cyber Futuristic**: Kombinasi Glassmorphism, Neon Glows, Gradient Animated, & Hologram Effect.
* **Background Interaktif**: Particle Canvas 60 FPS + Dynamic Mouse Spotlight.
* **Loading Screen**: Animasi RGB Spinner dengan progress tracker dinamis.
* **Dashboard Aset Digital**: Tampilan Finansial & GitHub Commit counter dengan animasi hitung naik.
* **Ripstory**: Fitur Highlight bergaya Stories Media Sosial dengan modal pop-up.
* **Ringan & Responsif**: 100% mendukung tampilan HP, Tablet, dan Desktop.

## 🚀 Cara Menjalankan Project
1. Clone atau download repositori ini.
2. Buka berkas `index.html` menggunakan peramban web modern (Google Chrome, Edge, Firefox, Safari).
3. Tidak memerlukan instalasi `npm` atau konfigurasi build tambahan.
